# `@dharma-ai-labs/agent-fabric-evidence-reduction`

Policy-bound local reduction for provider trajectories. It creates bounded,
redacted capsules plus deterministic coverage, completion, runtime, and
tool-discipline signals while keeping complete evidence in the encrypted local
vault by default.

These signals select sessions for deeper review. They cannot determine factual
grounding, inference validity, sycophancy, or a semantic remediation without
approved content evidence.
