# `@dharma-ai-labs/agent-fabric-policy`

Fail-closed organization and workspace policy for Agent Fabric evidence,
registered commands, paths, network access, Git authority, budgets, retention,
and disclosure modes. Local configuration may narrow organization policy but
cannot broaden it.
