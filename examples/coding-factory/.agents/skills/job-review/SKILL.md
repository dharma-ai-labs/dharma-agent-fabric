# Job Review

## Skill provenance prerequisite

Before dependent work, apply the [shared provenance procedure](https://github.com/dharma-ai-labs/dharmamegha/blob/main/docs/foundation/09-skill-provenance-and-adherence.md) from `dharma-ai-labs/dharmamegha` at the intended approved commit. Capture the resolved source/path, declared version, actual read-byte hash, approved revision, comparison and required dependencies; retain the receipt with the result. Installed copies must retrieve the verified shared source. Hold consequential reliance on failed/unavailable verification. Assess workflow adherence and outcome separately; a matching load does not prove either.

Read the repository's signed catalog and lexicon before reviewing job behavior.
Identify the logical job separately from each attempt. Check the tests for a new
attempt on the same job, tenant isolation and invalid inputs without side effects.
Ask the repository's Reviewer for bounded clarification when evidence is missing.
Report actual test commands and outcomes. Keep unsupported claims unresolved.
