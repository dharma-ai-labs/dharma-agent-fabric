# Agent-to-Agent Communication

Use one organization conversation across local and managed agents.

A message should contain:

- prose request;
- structured workflow status;
- failed gates;
- missing authority;
- permitted and forbidden actions;
- required recovery;
- evidence references;
- target selector;
- expiry.

Prefer structured state over asking the receiving agent to reconstruct a decision from prose. Preserve delivery and application acknowledgements for task-critical handoffs.
