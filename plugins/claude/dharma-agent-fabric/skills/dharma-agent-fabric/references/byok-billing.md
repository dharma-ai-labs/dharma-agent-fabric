# BYOK and Billing

## BYOK local

The local provider uses the developer's existing authentication. Dharma does not receive the credential and does not charge model tokens for that local agent execution.

Dharma may charge Analysis Tokens for server-hosted semantic judgment, rubric proposals, failure clustering, remediation synthesis, held-out judging, or scenario generation.

## Managed

Dharma charges Environment Tokens for managed coding-agent, replay, tool, and model execution.

## Before a billable action

Show purpose, model or environment, expected range, hard cap, payer, fallback, and whether deterministic-only analysis is available.
